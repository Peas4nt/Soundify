# 🎵 Soundify

Final Graduation Project | 4th Year Programming Technician

---

## 🚀 Features

- 🎧 **Play music in real-time** — locally uploaded or via SoundCloud
- 👤 **User profiles** — follow other users and explore what they’re listening to
- 📂 **Custom playlists** — create, save, share, and keep them private or public
- ❤️ **System-generated lists** — Recently played, Favorites, Most listened

---

## 🛠️ Tech Stack
**Backend:**
- Node.js + Express
- EJS
- PostgreSQL
